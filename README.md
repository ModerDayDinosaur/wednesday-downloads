# A Week From Wednesday — downloads

Installers for [A Week From Wednesday](https://www.ctrlcolab.com/wednesday), an
invoicing and accounts-receivable app for freelancers, published by CTRL Colab LLC.

**There is no source code here.** This repository exists so that the download
links in customer receipts resolve to a public URL: a private repository's
release assets return 404 to anyone without a GitHub login, which looks to a
buyer like a broken purchase.

## Getting the app

Use the download links on the product page rather than a URL from here — they
always resolve to the current release:

- Windows — <https://www.ctrlcolab.com/wednesday/download/win>
- macOS — <https://www.ctrlcolab.com/wednesday/download/mac>

Everything is also on the [Releases](../../releases) page, with a SHA-256 for
each file in the release notes.

## Asset names

The filenames are part of the contract — the download route matches on their
suffixes, and links already sent to customers depend on them.

| Platform | File |
|---|---|
| Windows installer | `AWeekFromWednesday-<version>-win64-setup.exe` |
| Windows portable ZIP | `AWeekFromWednesday-<version>-win64.zip` |
| macOS | `AWeekFromWednesday-<version>-macOS-arm64.dmg` |

## A licence is required

The app is inert without one. Buying it emails you a serial, which activates on
up to two computers. See the [help guide](https://www.ctrlcolab.com/wednesday/help/)
for what activation sends and what happens when you are offline (it keeps
working).
